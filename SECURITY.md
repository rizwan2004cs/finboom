# Security Policy

We take the security of FinBoom seriously — it handles people's personal financial data.

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.**

Instead, use one of these private channels:

1. **GitHub Security Advisories (preferred):** go to the repository's **Security** tab → **Report a vulnerability**.
2. **Email:** mohammad22cse@gmail.com with the subject line `FinBoom security`.

Please include:

- A description of the vulnerability and its potential impact.
- Steps to reproduce (proof-of-concept if possible).
- Affected URLs, routes, or files.
- Any suggested remediation.

## What to expect

- **Acknowledgement** within 3 business days.
- An assessment and, where valid, a fix timeline.
- Credit in the release notes once the issue is resolved (unless you prefer to remain anonymous).

## Scope

In scope: this repository's source code and the hosted app at `finboom-cyan.vercel.app`.

Out of scope: vulnerabilities in third-party providers (Clerk, Supabase, Sanity, Vercel) — please report those to the respective vendor. Reports that require physical access, social engineering, or denial-of-service testing are also out of scope.

Thank you for helping keep FinBoom and its users safe.
